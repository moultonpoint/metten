# Runtime interface font

Inter Variable (normal) is bundled locally for the owner's requested product-brand
integration. The app uses weights 400, 500 and 600, with tabular lining numerals.
No runtime font service or download is used. The outlined Clash logo remains in
its existing approved SVG; no logo font software or new artwork was added.

Source: [official Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1),
commit `e3a3d4c57d5ecc01453a575621882a384c1995a3`,
`docs/font-files/InterVariable.woff2`. Tag and immutable-commit downloads matched.
SHA-256: `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`.
The unmodified [OFL license](OFL.txt) is from that same commit, SHA-256
`262481e844521b326f5ecd053e59b98c8b2da78c8ee1bdbb6e8174305e54935a`.

This is a product runtime asset, separate from the originally delivered static
[brand kit](../brand/README.md). Keep its license with the font.
