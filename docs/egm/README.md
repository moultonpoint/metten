For expanded audits, read shared files in full; the foundation-only projection filter does not apply to that route. Daily audits retain the exclusions below.

`docs/proposals/**` contains historical intake, drafts, reviews and source captures. Follow the evidence index to [the operative approved design](../proposals/issue-4-egm/strategy-rules-design.md); do not treat every archived proposal or continuation prompt as a requirement. New maintained paths or behavior without documented ownership are findings or explicit coverage gaps, never silently excluded.

### Other exclusions

Ignored private research/planning and runtime data, secret values/private credential records, `.git/`, dependency installations, generated `src-tauri/gen/`, `target/`, `dist/`, `.scratch/` and temporary verifier resources are not maintained implementation inputs. Follow `.gitignore`; do not read secret/private records to perform drift reporting. Include hidden maintained configuration such as `.github/` and `.gitignore` in the coverage check.

## Invariants

- Trace each in-scope component to a contract and compare in both directions: documented behavior versus current code, and code versus documentation coverage. A new undocumented file or behavior is a finding even if the existing contracts still match.
- Source-grounded observations do not override the product specification, accepted ADRs or issue acceptance criteria. Record contradictions rather than blessing current code by copying it into a README.
- Preserve the distinction between effective control, accepted requests and confirmed saved state; dummy credential proof is not real account/provider integration. No paper/live behavior or release readiness is established here.
- Historical records retain original results and limitations. Later finished checkpoints supersede earlier incomplete states; old CI wording is not current remote status. No fresh test result is implied by a source inspection.

## Side Effects

Drift checking reads maintained source/docs and writes a dated Markdown report. It does not modify source, credentials, runtime state, requirements or inspected contracts. Fixing a discrepancy is separate bounded work. No scheduled job or new dependency is required.

Write docs/egm/YYYY-MM-DD_DRIFT_REPORT.md with a section per inspected
