Have the next market ready before this one ends.

What if the next market is not ready?

Show “Next market not ready — checking its information.” Make a small number of spaced checks. Never keep asking in a tight loop, and never use the old market’s prices for the new one.

A late arrival can be shown when verified. It does not automatically let a strategy enter a market whose start it missed.

What carries forward?

Useful Bitcoin price history can continue. The new market gets its own prices and a fresh start for the conditions that belong to that market. Unfinished information is never treated as complete.

Fast means useful information arrives in time.

Receive without interruption

Opening a screen should not create extra provider requests. Slow screen updates should not hold up incoming prices.

Finish the work promptly

We measure the full journey to usable information, including work still waiting to be processed.

Handle a busy moment

We test a rush of updates. Metten must preserve meaningful changes or clearly say it cannot keep up.

Recover honestly

A fresh price can return before the needed past prices are complete. Metten must show both facts.

Why we do not promise “no timeouts”

Providers and networks can fail. The plan limits how long Metten waits, how often it tries again, and how many requests it makes. During uncertainty, affected information is marked unusable.

What we will prove before trusting it.

It reads the right information.

Test the wrong market, old prices, repeated updates and missing updates.

It stays responsive under pressure.

Test busy periods while the screen and other normal work are active.

It respects provider limits.

Count requests and repeat attempts. Stop repeated attempts when a connection is refused or you choose Stop.

Its claims match the evidence.

Record the computer, workload and results. Separate controlled tests from actual provider access.

Make the next change easy to find.

Each responsibility has one clear home. The guide tells the next person where to change it and which check proves it still works.
